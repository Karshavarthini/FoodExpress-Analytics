# FoodExpress Project

## Project Overview

FoodExpress is a Python-based food delivery analytics project developed using different Python concepts.

## Technologies Used

- **Python**
- **NumPy**
- **Pandas**
- **Matplotlib**
- **OpenPyXL**

## Project Structure

- **01_foodexpress_python.py** – Phase 1 to Phase 7
- **02_foodexpress_analysis.py** – Phase 15 to Phase 17
- **03_foodexpress_numpy_pandas.py** – Phase 18 to Phase 19
- **data/** – Stores input and output data files
- **outputs/** – Stores generated charts

## Phases Covered

### Phase 1 – Basic Billing

- Take restaurant details as input
- Calculate subtotal
- Calculate GST

- Check free delivery eligibility
